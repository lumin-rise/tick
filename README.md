# TICK —— 桌面看盘软件

深色主题桌面看盘应用（Tauri 2 + Rust + React/TypeScript），核心能力：**同步手机同花顺的自选股和分组**，配合腾讯实时行情秒级刷新。

## 功能

- **同花顺自选同步**：账号密码登录（RSA 加密直发官方接口），自动拉取手机 App 里的全部分组和"我的自选"，默认 5 分钟自动同步一次
- **实时行情**：腾讯批量行情接口，默认 3 秒一轮，红涨绿跌，上证/深成/创业板/科创50 指数常驻底栏
- **市场筛选**：ALL / CN（沪深北）/ HK / US 分市场 Tab（CRYPTO 预留）
- **本地自选**：手动添加任意市场代码（600519 / 00700 / AAPL 自动识别市场），不影响同花顺数据
- **K 线详情**：点击个股查看日 K（前复权，MA + 成交量）与当日分时（价格线 + 均价线）
- **窗口置顶**：顶栏 📌 一键置顶看盘
- 虚拟滚动列表（几千只无压力）、列排序、精简/详细视图切换

## 快速开始（开发模式）

前置要求：Node 18+、Rust（rustup，MSVC 工具链）、VS Build Tools（含 VC++ 与 Windows SDK）。

```
双击 启动开发模式.bat
```

或手动：

```bash
npm install
npm run tauri dev
```

> 注意：在 Git Bash 里直接跑 cargo 可能命中 GNU `link` 而非 MSVC `link.exe`，`启动开发模式.bat` 已通过 vcvars64 处理。

## 打包

```
双击 构建安装包.bat
```

产出 NSIS 安装包与独立 exe（`src-tauri/target/release/`）。

## 同花顺登录说明

**推荐：验证码 / 扫码登录（免密码）**。设置 → 「验证码 / 扫码登录」→ 打开登录窗口：

- **短信验证码**：输入手机同花顺绑定的手机号，收验证码登录（手机 App 用券商账户登录的也能用，自选云同步挂在该手机号下）
- **扫码**：直接用手机同花顺 App 扫一扫，无需任何账号密码

登录成功后页面自动跳到自选股页，软件自动提取登录态完成同步并关闭窗口；没触发的话点「我已完成登录」。

备选方式：

1. **密码登录**：手机号 + 同花顺密码（RSA 加密直发官方接口）。忘了密码点「忘记密码？」跳官方重置页 `upass.10jqka.com.cn/lostpass`。
2. **手动导入 Cookie**（兜底）：浏览器登录后复制整段 cookie 粘贴导入。

cookie 保存在本地应用数据目录，约 24 小时过期后自动提示重登。同步为**只读**：软件不会修改你手机里的自选数据；软件内添加的股票保存在"本地"分组。

## 数据源

- 实时行情 / K线 / 分时：腾讯财经公开接口（qt.gtimg.cn / web.ifzq.gtimg.cn）
- 自选分组：同花顺移动端内部接口（参考开源项目 [ths-favorite](https://github.com/sunnysab/ths-favorite) 的协议逆向）

## 项目结构

```
src/                  React 前端
  components/         顶栏/工具条/分组栏/列表/弹窗
src-tauri/src/
  quotes.rs           腾讯行情引擎（批量轮询 + event 推送）
  ths/auth.rs         同花顺 RSA 登录协议
  ths/groups.rs       分组拉取与 content 解析
  kline.rs            日K / 分时
  state.rs            全局状态 + 调度（行情 3s / 同步 5min）
  store.rs            本地持久化（app data 目录 stocker.json）
```
